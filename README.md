# 🚀 Payment Gateway Simulator

Платёжный шлюз-симулятор для изучения асинхронной обработки платежей, очередей и оптимизации баз данных.

## 📋 О проекте

Проект имитирует работу платёжной системы с асинхронной обработкой транзакций через очереди. Подходит для:
- Изучения RabbitMQ в Laravel
- Практики оптимизации PostgreSQL
- Нагрузочного тестирования
- Подготовки к собеседованиям

## 🛠 Технологии

| Технология | Версия | Назначение |
|------------|--------|------------|
| Laravel | 12.x | PHP фреймворк |
| PHP | 8.4+ | Язык программирования |
| PostgreSQL | 16 | База данных |
| RabbitMQ | 3.13 | Брокер сообщений |
| Redis | 7.x | Кеширование / идемпотентность |
| Nginx | Alpine | Веб-сервер |
| Docker | Latest | Контейнеризация |
