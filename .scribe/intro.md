# Платёжный шлюз API

Документация для интеграции с платёжной системой.

## Аутентификация
Используется Laravel Sanctum. Передавайте токен в заголовке:
`Authorization: Bearer ваш_токен`

## Эндпоинты
- `POST /api/payments` — создание платежа
- `POST /api/webhook/gateway` — колбек от платёжной системы

## Форматы
- Все запросы и ответы в формате JSON
- Валюты: USD, EUR
